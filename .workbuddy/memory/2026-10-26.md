# 2026-10-26

## MiMo Voice Studio 从零搭建完成

基于小米 MiMo 开放平台官方文档，构建 TTS + ASR Web 应用，全链路已跑通（36 项冒烟测试全通过）。

### 官方接口结论（已核实）
- TTS 与 ASR 共用同一 OpenAI 兼容端点：`POST https://api.xiaomimimo.com/v1/chat/completions`
- 鉴权：`api-key: $MIMO_API_KEY` 或 `Authorization: Bearer xxx`（代码里两个头都带）
- TTS 模型：`mimo-v2.5-tts`（预置音色）/ `mimo-v2.5-tts-voicedesign` / `mimo-v2.5-tts-voiceclone`
  - 必须带 `role=assistant` 消息，content 为待合成文本
  - 音频在 `choices[0].message.audio.data`（base64）
  - 预置音色：mimo_default / 冰糖 / 茉莉 / 苏打 / 白桦 / Mia / Chloe / Milo / Dean
- ASR 模型：`mimo-v2.5-asr`，仅 wav/mp3，data URL 形式传入，base64 后 ≤10MB
  - 结果在 `choices[0].message.content`，时长在 `usage.seconds`
- 限流：RPM 100；ASR TPM 10K

### 技术选型
- 后端：FastAPI + SQLAlchemy 2.0 + Pydantic v2 + PyJWT + httpx
- 密码用 stdlib PBKDF2-SHA256（20 万次迭代），**刻意避开 bcrypt/passlib**，避免 Windows 编译与版本兼容问题
- 前端：原生 HTML/CSS/JS，无构建步骤；Web Audio AnalyserNode 驱动波形可视化
- 设计：浅色主题，小米橙 #E8541B（TTS）+ 深青 #0E4F5C（ASR）做功能区分，字体首选 MiSans

### 关键决策
- **模拟模式（MOCK_MODE）**：未配置 API Key 时本地生成 WAV 提示音返回，保证无密钥也能验证全链路。这是让应用"开箱可运行"的关键。
- 微信登录完全可配置：AppID/Secret 留空则 `/api/auth/wechat/*` 返回 404，前端隐藏入口，账密登录不受影响。
- 调用前先落 `status=pending` 记录，成功/失败都更新并写 `error_message`，失败也留痕。
- 音频下载支持 `?token=xxx` 查询参数鉴权（`<audio>` 无法自定义请求头）。

### 踩过的坑
1. `tts_service.synthesize` 里 `request_id` 只在 live 分支赋值 → mock 模式 UnboundLocalError 500。已在函数开头初始化。
2. FastAPI `RequestValidationError.errors()` 的 `ctx` 里含 ValueError 对象，直接塞进 JSONResponse 会 `TypeError: not JSON serializable` → 500。已在 `errors.py` 中精简为仅含 loc/msg/type。
3. `urllib` 发带中文 query 的请求需要手动 `quote`，否则 ascii 编码报错。
