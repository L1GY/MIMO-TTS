### 品牌彻底清理
- 应用改名为「声坊 Voice Atelier」，之前叫 MiMo Voice Studio。
- 前端 static/ 全目录 0 处上游品牌残留（文案、title、favicon、alt、placeholder、注释）。
- 后端 app/ + run.py + smoke_test.py 0 处残留。
- **关键手法**：把上游协议值（模型 ID、预置音色 ID、默认音色）全部外置到 `.env`
  （`TTS_MODEL` / `TTS_MODEL_DESIGN` / `TTS_MODEL_CLONE` / `ASR_MODEL` / `TTS_DEFAULT_VOICE` / `TTS_PRESET_VOICES`）。
  这样 `build_payload` 里的模型分支比较也改成跟 settings 比，源码不再出现任何上游字面量；
  前端所需模型由 `/api/tts/options` 动态下发（前端原本在 `<option value="mimo-v2.5-tts">` 里写死）。
- 仅剩 `.env` / `.env.example` 含 7 行上游协议值——这是调用 API 必需的，属服务端配置，无法消除。
