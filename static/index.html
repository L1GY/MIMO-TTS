API 文档

页面上的每一步操作都对应一个后端接口，可直接接入你自己的程序

方法路径说明
POST/api/auth/login账号密码登录，返回 access_token
POST/api/tts/synthesize文本转语音：text / voice / speed / pitch / sample_rate
POST/api/tts/preview音色一键试听，不写入历史
POST/api/asr/transcribe上传音频转文字：multipart file / language / punctuate / segment
GET/api/history分页查询历史记录，支持 type 与 keyword
GET/api/tts/{id}/download下载生成的音频

全部接口需要 Authorization: Bearer <token>； 完整交互文档见 /docs。
